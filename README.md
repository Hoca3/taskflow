# TaskFlow

A minimal full-stack task manager application.

## Tech Stack

Frontend:
- React
- Vite

Backend:
- Spring Boot
- H2 Database

## Features

- Add tasks
- Delete tasks
- Mark tasks as completed

## Project Structure

```text
frontend/
backend/
```

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```

## Run Backend

```bash
./mvnw spring-boot:run
```
